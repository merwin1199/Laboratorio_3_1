Descripción:
En este proyecto se creó una página web básica utilizando HTML5 y CSS.
La actividad permite practicar la estructura de una página web, el uso
de elementos HTML, elementos semánticos y algunas características de HTML5.

Elementos utilizados:
- HTML y HTML5 para crear la estructura de la página.
- CSS para diseñar y organizar la presentación.
- Elementos semánticos como header, nav, main, section, article y footer.
- Elementos multimedia como video y audio.
- Elementos figure y figcaption para organizar imágenes.
- Canvas para mostrar un ejemplo de contenido gráfico mediante JavaScript.
- Enlaces y listas HTML.

Características principales de HTML5:
HTML5 permite utilizar elementos semánticos que ayudan a organizar mejor
el contenido de una página. También incorpora elementos multimedia como
video y audio, además de herramientas como canvas para crear contenido
gráfico. Estas características permiten desarrollar páginas más
estructuradas y funcionales.
